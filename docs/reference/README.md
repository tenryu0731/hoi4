# HOI4 のインターフェイス — タブごとの参照と差分

このフォルダの画像は Hearts of Iron IV の実機スクリーンショットで、**設計の参照**として
置いてある。ここから読み取った寸法・階層・配色を仕様として書き下し、実装はそれを見て行う。
画像そのものを素材として取り込むことはしない。

## 全タブに共通する、HOI4 がやっていてこちらがやっていなかったこと

1. **すべての実体に図像がある。** 装備には車輌のシルエット、建物にはアイコン、技術には
   その兵器の絵、方針には固有の紋章。こちらは長らく文字だけだった。
2. **枠が立体である。** どの枠も上辺に暖色の光を受け、下辺に硬い影を落とす。
   `--bevel` はこれを写したもの。
3. **数値は大きく明るく、名前は小さく暗い。** 逆にすると表が読めなくなる。
4. **構造そのものを見せる。** 方針も研究も「ツリー」であり、リストではない。
   前提と排他がどこへ繋がるかが見えることが、その画面を見る理由になっている。

## 国家方針（`hoi4-focus-tree.jpg`）

- 方針は **格子上のノード**で、前提は線で結ばれる。線は肘（縦→横→縦）を描く。
- 排他の対（例：Forced Quebec Conscription ⟷ Compromise With Quebec）は
  **点線の水平線**で結ばれる。
- 未解放の枝も**描かれている**。隠されていたら、その先に何があるか見えない。
- 各ノードは 円形／盾形の紋章 ＋ 2〜3 行の名前。
- 左下に「継続国家方針」の別枠。

**実装状況**：`3c7e916` でツリー化済み。ノードは 84×72、格子 96×86。
線は SVG で肘を描き、完了済みの親からは緑、未解放は灰、排他は赤の点線。
紋章は固有絵ではなく**効果の種類**から選ぶ（工場・研究・戦争目標・併合…）。
82 個ぶんの固有絵は現実的でないうえ、「何をする方針か」はリスト表示では
そもそも見えていなかった情報である。

**残差**：継続国家方針が無い。ノードの紋章が固有でない。

## 研究（`hoi4-research-tree.jpg`）

- **年が列**（1922 / 1936 / 1940 / 1944）、**艦種が行**（駆逐艦・巡洋艦・戦艦…）。
- 各セルは 装備のシルエット ＋ 名称 ＋ ローマ数字の世代。
- 研究済みは金、研究可能は明るい灰、未解放は暗い。世代間は線で結ばれる。
- 上端に分野タブ（陸・空・海・工業…）。
- 右に選択中の技術のカード：説明文、性能表、生産コスト。

**残差**：こちらは分野を切り替える平坦なリスト。年の列も世代の線も無い。

## 生産（`hoi4-production.jpg`, `hoi4-production-variant.jpg`）

- 左端に縦一列の生産ライン。各行が：
  - 順位番号 ＋ 装備名 ＋ **装備のシルエット**
  - 日産（`176.27/day`）と効率バー
  - `x10` `x5` の割当ステッパーと工場数
  - 在庫数と、部隊が必要としている数
- 上部に 軍需工場 `71/84`、造船所 `36/36`、資源の帯。
- バリアント作成は別窓：装甲・主砲・信頼性・エンジンの ± と、
  変更が性能に与える差分（`27.7▲`）。

**残差**：こちらは装備名と工場数のテキスト行のみ。シルエットも効率バーも無い。

## 徴兵・師団デザイナー（`hoi4-division-designer.jpg`）

- 左に**大隊の格子**（前線 5 列 × 5 段、支援 5 段）。空きは `+`、未解放は錠前。
- 右に 基本性能・戦闘性能・装備コストの三列表。
- 下に地形ごとの補正（Adjusters）。
- 下端に `Reset` `Duplicate` `Update` と推定生産コスト。

**残差**：こちらは大隊を文字リストで並べている。格子でも図像でもない。

## 軍・戦闘計画（参照画像なし。HOI4 の挙動から再現）

このタブだけ実機スクリーンショットが手元になく、開発日記と実際の操作系から
仕様を起こした。HOI4 が「軍」でやっていることは四つある。

1. **師団は軍に属し、軍は将軍に属す。** 軍集団は軍を持ち、元帥の能力の半分が
   配下の将軍全員に届く。指揮限界を超えると能力が線形に薄まる（禁止ではない）。
2. **前線は命令であって目的地の列ではない。** 「この国と接する自国州を保持せよ」
   と言うと、毎日その州を計算し直し、国境が動けば軍もついて動く。
3. **準備ボーナス。** 計画の上で止まっている間、1 日 2%、上限 30%（将軍の
   計画能力で上がる）。動き出すと 1 日 1% 失う。
4. **地図の上に線が出る。** 命令は必ず地図に描かれる。描かれない命令は
   プレイヤーにとって存在しない。

**実装状況**：1〜3 は `sim/military/command.ts` と `sim/military/frontline.ts` に
以前から入っていた。欠けていたのは 4 と、そこへ至る操作だった。

- `MapRenderer.drawPlans` が `army.frontProvinces` を**地面の上に**描く。
  線は「計画の州」と「計画外かつ自国支配でない州」が共有する弧＝外向きの面。
  州ごとに小さな点を打つので、内陸の駐屯命令も見える。進攻命令には目標へ矢印。
- 色は編成ごとに変える（同じ国境に二個軍がいるとき区別が要る）。移動命令の
  淡い金 `0xf2d98a` と紛れない色だけを使う。
- 長押ししてなぞると**範囲選択**。掴むのはカウンターであって州ではない
  ——プレイヤーは見えている部隊を囲っている。
- 選択したら地図の上の命令バーで「軍へ編成」「戦線を引く」。
  戦線の相手は**国を選ぶ**方式にした。412px の画面で国境を指でなぞって
  線を引くのは精度が出ない。HOI4 のドラッグの代替であって、意味は同じ。

**残差**：軍集団の階層を地図から操作できない。進攻の目標は VP 上位 4 州の
自動選択で、任意の州を選べない。
